# MyTelegramChannel — Android offline password gate

پروژه اندروید نمایش کانال **عمومی** تلگرام داخل برنامه با رمز محلی و قابل تغییر روی همان گوشی. لینک کانال را پس از نصب در تنظیمات وارد کنید.

[راهنمای فارسی](README_FA.md) | [ساخت و دریافت APK](../../actions/workflows/build-apk.yml)

- بدون Cloudflare و بدون سرور
- بدون نیاز به حساب تلگرام برای پیش‌نمایش عمومی
- رمز مشترک بین دستگاه‌ها **نیست**؛ رمز هر نصب جداگانه ذخیره می‌شود.
- عمومی بودن کانال به این معناست که محتوای آن بیرون از برنامه نیز قابل مشاهده خواهد بود.
