# MyTelegramChannel

برنامه اندرویدی نمایش یک کانال **عمومی** تلگرام درون WebView با رمز مشترک مدیریت‌شده در Cloudflare Worker. این رمز فقط ورود به برنامه را کنترل می‌کند؛ خود کانال عمومی بیرون از اپ قابل مشاهده است.

## دریافت APK
پس از قرار گرفتن فایل‌های پروژه، به [Actions](https://github.com/ahbe0911-cmd/MyTelegramChannel/actions/workflows/android-apk.yml) بروید، آخرین اجرای موفق «Build Android APK» را باز کنید و از بخش **Artifacts** فایل `MyTelegramChannel-debug-apk` را دانلود کنید. فایل ZIP دانلودشده را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.

## راه‌اندازی سرویس
برای کارکرد واقعی ورود، Cloudflare Worker داخل پوشه `server` و پایگاه‌داده D1 را راه‌اندازی کنید و نشانی HTTPS را به‌عنوان متغیر مخزن `GATEWAY_URL` در GitHub Actions تنظیم کنید. بدون آن، APK ساخته می‌شود ولی ورود به کانال کار نمی‌کند. رمز، کلید مدیر و کلیدهای سرویس را فقط در Cloudflare Secrets نگه دارید؛ آن‌ها را در مخزن عمومی وارد نکنید.

نام عمومی کانال را پس از ورود از بخش «تنظیمات مدیر» تعیین کنید. این برنامه کلاینت کامل تلگرام نیست و فقط پیش‌نمایش وب پست‌های عمومی در `t.me/s/<username>` را نشان می‌دهد.
