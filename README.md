# MyTelegramChannel

پروژه اندروید نمایش کانال **عمومی** تلگرام در داخل برنامه همراه با ورود با رمز مشترک و تنظیمات مدیر.

- راهنمای کامل: [README_FA.md](README_FA.md)
- [ساخت APK در GitHub Actions](../../actions/workflows/build-apk.yml)
- برای استفاده از رمز مشترک و مشاهده کانال باید ابتدا Cloudflare Worker و پایگاه‌داده D1 طبق راهنما راه‌اندازی شوند و نشانی Worker به‌عنوان متغیر مخزن `API_BASE_URL` تنظیم شود. APK بدون تنظیم این سرویس ساخته می‌شود، اما صفحه ورود آن کار نخواهد کرد.

کانال عمومی خارج از برنامه نیز قابل مشاهده است؛ رمز فقط ورود به این برنامه را محدود می‌کند.
