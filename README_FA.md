# کانال من — نسخه اندروید بدون سرور

این نسخه از **رمز محلی روی هر گوشی** استفاده می‌کند و هیچ سرویس Cloudflare، متغیر GitHub یا حساب تلگرام لازم ندارد.

## ساخت و دانلود APK
در مخزن GitHub وارد Actions > Build Android APK شوید. اجرای موفق را باز کنید و فایل MyTelegramChannel-Local-APK را از Artifacts دانلود کنید. ZIP را استخراج و app-debug.apk را نصب کنید.

## نحوه استفاده
1. در نخستین اجرای برنامه، یک رمز ۶ تا ۱۲۸ نویسه وارد و تکرار کنید.
2. در صفحه تنظیمات، آدرس کانال عمومی خود مانند https://t.me/mychannel را وارد و ذخیره کنید؛ می‌توانید این کار را بعداً انجام دهید.
3. با زدن «نمایش کانال»، پیش‌نمایش عمومی تلگرام درون برنامه باز می‌شود.
4. از بخش تنظیمات با وارد کردن رمز فعلی، رمز جدیدی برای همان گوشی تعیین کنید.
5. دکمه «قفل کردن برنامه» به صفحه ورود بازمی‌گردد. اگر رمز را فراموش کنید، قابلیت بازیابی وجود ندارد.

**محدودیت مهم:** چون کانال عمومی است، اشخاص همچنان می‌توانند بیرون از برنامه در تلگرام آن را مشاهده کنند. رمز فقط رابط این برنامه در همان گوشی را قفل می‌کند. رمز بین دستگاه‌ها هماهنگ نیست. پیش‌نمایش t.me/s/ ممکن است بعضی پست‌ها یا رسانه‌ها را کامل نمایش ندهد. خروجی GitHub Actions فایل debug است و برای انتشار حرفه‌ای باید با کلید خودتان release امضا کنید.

پوشه server از نسخه قبلی در مخزن باقی مانده اما برای این نسخه به کار نمی‌رود.
